# QCALVIEW — User manual

## About QCALVIEW
QCALVIEW is developed by **Fabrice Kerzerho — ArcTan°**, a French practice specialising in visual simulation and geomatics, including landscape assessment support, renewable-energy projects, photographic simulations and GIS workflows.

- QCALVIEW: https://qcalview.com
- ArcTan°: https://arctan.fr
- Contact: contact@arctan.fr

## Purpose
QCALVIEW brings photographic calibration and visual simulation workflows directly into QGIS. It can associate photographs with viewpoints, project GIS layers into calibrated views, create schematic representations, support visibility/occultation work and export prepared views.

## Quick start
1. Load or select a point layer representing viewpoints.
2. Add or select a viewpoint and associate a photograph when required.
3. Set the projection and camera parameters (yaw, pitch, roll, HFOV/VFOV and camera height).
4. Add compatible vector layers to the projected-layer list.
5. Configure layer appearance or schematic representations.
6. Check the preview/viewer and save the viewpoint parameters and visual state.
7. Use the Export tab for the required output.
